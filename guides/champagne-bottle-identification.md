# Champagne bottle identification and release verification

Prestige Champagne often exists in multiple releases that look deceptively similar. Before comparing price or maturity, identify **exactly which bottle is being sold**.

## 1. Separate five different identifiers

Do not treat these as interchangeable:

1. **Cuvée** — the wine itself, such as a house prestige cuvée.
2. **Vintage** — harvest year for a vintage-dated wine.
3. **Release tier** — original release, late release, library release, etc.
4. **Edition / sequence** — used by some non-vintage multi-year blends.
5. **Bottle format** — 375 mL, 750 mL, magnum, and larger formats can mature differently and trade at different premiums.

A listing that gives only the producer and vintage can still be incomplete.

## 2. Original release vs. late release

A late-disgorged or library release is not simply “the same wine with more age.”

Differences can include:
- longer lees aging before disgorgement;
- later disgorgement date;
- different dosage;
- additional post-disgorgement bottle age;
- distinct packaging and market positioning.

Never infer the release tier from price alone.

## 3. Disgorgement date matters

For many serious Champagnes, disgorgement information helps explain the wine's development.

Why it matters:
- time on lees affects texture and aromatic development;
- post-disgorgement age is a separate clock;
- two bottles of the same cuvée and vintage can therefore show differently.

If the producer publishes a disgorgement code or bottle-specific lookup, prefer that over merchant shorthand.

## 4. Edition numbers are not vintages

Some houses use numbered editions for non-vintage blends. An edition may correspond to a base year or release sequence, but it is not automatically a vintage wine.

When comparing editions, record:
- edition number;
- base vintage if officially disclosed;
- release date;
- disgorgement information if available.

## 5. Merchant listings can collapse distinct SKUs

Common failure modes:
- stock photo shows a different vintage;
- title says one release while description describes another;
- product page is reused across vintages;
- gift-box and non-gift-box stock are mixed;
- bottle size is buried in a variant selector;
- late-release terminology is used loosely.

For expensive bottles, verify the actual SKU before purchase.

## 6. Verification hierarchy

Use this order where possible:

1. producer technical sheet or bottle-lookup tool;
2. official importer / distributor sheet;
3. merchant photo of the exact bottle;
4. merchant written confirmation;
5. secondary databases and reviews.

Secondary tasting notes are useful for style, but they are weaker evidence for the exact commercial SKU.

## 7. Photograph checklist

For a mature or expensive bottle, useful images include:

- front label;
- back label;
- neck label / capsule;
- bottle base;
- fill level;
- cork area and capsule condition;
- packaging;
- any laser, lot, or disgorgement code.

Do not rely on a single polished stock image.

## 8. Condition and identity are separate questions

A perfectly identified bottle can still have poor provenance. A beautifully stored bottle can still be misidentified.

Evaluate both:

### Identity
- correct producer;
- correct cuvée;
- correct vintage / edition;
- correct release tier;
- correct format.

### Condition
- storage history;
- fill;
- seepage;
- capsule;
- label condition;
- transport exposure.

## 9. Build a bottle record

For serious purchases, record:

| Field | Why it matters |
|---|---|
| Producer | identity |
| Cuvée | identity |
| Vintage / edition | identity |
| Release tier | original vs. late release |
| Disgorgement | maturity context |
| Dosage | style context |
| Bottle size | maturation / price |
| Packaging | SKU and resale context |
| Merchant | provenance chain |
| Purchase date | audit trail |
| Bottle photos | verification |

## 10. Price comparison rule

Only compare like with like.

A price table becomes misleading if it mixes:
- original and late release;
- different bottle sizes;
- gift box and loose bottle;
- in-stock and pre-arrival;
- tax-inclusive and tax-exclusive pricing;
- refrigerated shipping and standard shipping.

Normalize the SKU first, then compare landed cost.

## Bottom line

For collectible or mature Champagne, identification should be treated like a data-cleaning problem. A surprising share of “great deals” disappear once the exact release, disgorgement, format, and condition are normalized.
